# 📱 Responsive Navbar

A clean and modern **responsive navigation bar** built with **HTML, CSS, and JavaScript**.  
This project demonstrates how to create a mobile-friendly navbar with toggle functionality, smooth transitions, and a scalable design pattern.

---

## ✨ Features
- 📐 **Responsive Design** – Works seamlessly on mobile, tablet, and desktop
- 🎨 **Modern Styling** – Built with CSS Flexbox/Grid
- ⚡ **Smooth Animations** – Transition effects for menu toggle
- 🧭 **Hamburger Menu** – Collapsible navigation for smaller screens
- 🔄 **Reusable Component** – Easy to integrate into any project
- 🌍 **Cross-Browser Compatibility** – Tested on major browsers

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3 (Flexbox/Grid)**
- **JavaScript (ES6+)**
